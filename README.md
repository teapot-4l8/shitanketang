# JCE 实验室安全学习助手（浏览器插件）

华北电力大学-实验室安全育人智慧学习系统（ncepu.jcedutec.cn）挂机刷课插件。
在浏览器里真实播放视频，由网站自身机制上报进度——时长能正常刷上去，不依赖旧的接口直刷。

## 安装（Chrome / Edge 通用）

1. 打开浏览器，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `jce-helper` 文件夹
4. 工具栏出现红色 ▶ 图标即安装成功

## 使用

1. 登录学习网站，打开**课程学习页面**（左侧能看到目录树的那个页面）
2. 点插件图标，确认课程列表已加载（右上角显示「就绪」）
3. 勾选要刷的课程，选倍速（默认 2.0x）和弹题模式（默认自动答题）
4. 点「▶ 开始挂机」，保持该标签页打开即可，可最小化窗口（**不要关闭标签页**）

## 功能说明

| 功能 | 说明 |
|---|---|
| 自动播放 | 静音自动播放当前视频，防暂停、防限速 |
| 自动切换 | 从接口拉知识树，跳过已学节点，按顺序点目录树切换到下一个未学视频 |
| 弹题处理 | 自动答题模式：优先用内置 943 题答案库，没命中就暴力试 A-D，答对的题干会自动学习记住 |
| 跳过答题 | 不作答，直接尝试关闭弹窗继续播（部分弹窗强制答题时自动回退为答题） |
| Token | 优先从页面自动抓取（登录过期重登后自动跟随）；手动填写的仅作兜底 |
| 进度角标 | 插件图标实时显示 已完成/总数 |

## 注意事项

- 倍速建议先试 **2.0x**；如果发现个别视频进度异常，降到 1.0x
- 偶发「接口兜底」提示是正常的（个别节点用上报接口补一刀）
- 如果日志提示「未在目录树中找到节点」，说明当前页面不是对应课程的目录树页，手动切过去即可，脚本会自动继续
